Where Unabyss lost a new user.

I planned to test whether two conflicting brand profiles stayed separate across AI tools. I never reached that test. The roadblock became the more useful finding.

Original test

Would one brand voice leak into another?

I work across accounts with rules that sometimes contradict each other. Unabyss promises a context layer that can carry a person’s working memory across AI tools, and its agency positioning made context separation the feature I actually wanted to test.

The plan was to create two profiles with opposing writing rules, generate content under each one, then switch between Claude and ChatGPT to see whether the separation held.

What failed

The vault said it was ready. It held nothing.

Setup ended with a message saying the product was ready to use. The dashboard showed zero memories stored, while displaying 14 minutes saved beside it.

I added four Notion notes and asked for three facts written inside one of them. The tool returned “restricted” for all three. That sent me into permissions and filters for roughly an hour.

One message made two different product states look like the same problem.

With the filters turned off, the answer changed: the facts were not restricted; they simply had not been imported. Page titles and database schema had arrived, but the page bodies had not.

Diagnosis

Four product messages pushed a new user in the wrong direction.

1. “Restricted” hid the real stateThe message sounded like a permission problem without saying a filter was involved—or that the information might not exist in the vault at all.
2. “All set” appeared too earlyA successful connection was presented as a successful import.
3. “Time saved” had no evidenceThe dashboard showed saved time while the memory count remained zero.
4. Metadata became a false profileThe system inferred a working style and active projects from Notion’s schema and sample rows instead of the notes I wrote.

Recommendations

Three copy changes, one larger product fix.

  1. 01

    Replace the restricted message with a neutral “nothing was found” state and name the active filters.

  2. 02

    Do not say setup is complete while the vault is empty. Confirm the connection, then point to the fastest import path.

  3. 03

    Hide “time saved” until something has actually been retrieved.

  4. 04

    Import page bodies, not only titles and schema.

Validation

The founder checked the logs.

The founder reviewed the account logs, confirmed the integration fault and said the problems were already being fixed.

The written exchange is retained as private project evidence rather than published here.

The result showed that a blocked test can still reveal something commercially useful when the experience is documented carefully and reframed around the moment a customer nearly leaves.

The original context-separation test remains unfinished. This case study does not claim that the separation feature failed.
